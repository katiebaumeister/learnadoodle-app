# 🎓 Unified Curriculum & Planning — UI Language Spec

Companion to **UNIFIED_CURRICULUM_ARCHITECTURE_SPEC.md**. This doc is the single source of truth for microcopy, labels, and tooltips so “slot vs lesson vs curriculum lesson” is consistent everywhere.

**Implementation:** Exact strings are in **`lib/constants/curriculumPlanningCopy.json`**. Use those keys in code so copy stays consistent. Plan My Year modal layout and heading hierarchy: **PLAN_MY_YEAR_MODAL_HEADING_REDESIGN.md**.

---

## Core Vocabulary (Non-Negotiable)

These terms must be used consistently everywhere:

| Concept | Official Term | Never Call It |
|--------|----------------|----------------|
| Time block generated by Plan My Year | **Instructional Slot** | lesson, class |
| Curriculum lesson definition | **Lesson** | event |
| Scheduled lesson on calendar | **Scheduled Lesson** | slot |
| Empty placeholder on calendar | **Empty Slot** | lesson |
| Parsed but not attached content | **Draft Lesson** | lesson |
| Unit container | **Unit** | course plan |
| One-off non-curriculum calendar item | **Event** | lesson |

This separation is critical.

## 1️⃣ Plan My Year Modal (Capacity Layer)

| Element | Copy |
|--------|------|
| **Modal title** | Plan My Year |
| **Subtitle** | Set when learning can happen and how much time is required. |
| **Apply button** | Generate Instructional Slots |
| **Never use** | “Generate lessons”, “Create lessons” |
| **Success toast** | ✅ 128 instructional slots generated (24 for Math, 18 for Reading…) |
| **Slot tooltip (calendar) — empty** | This is an instructional slot created by Plan My Year. Fill it with a lesson or leave it open. |
| **Slot tooltip (calendar) — filled** | This slot contains a scheduled lesson. It will not be changed by future plan updates. |
| **Warning when reapplying (if filled slots exist)** | Some slots already contain scheduled lessons. Only empty slots will be updated. |

## 5️⃣ Calendar Slot States (Critical UX Layer)

| State | Label | Button / secondary |
|-------|--------|--------------------|
| **Empty slot** | Instructional Slot | **Fill Slot** — Secondary: Create One-Off Event |
| **Filled slot** | Scheduled Lesson — From Unit: [Unit name] | Hover: This lesson is linked to curriculum and will not be overwritten. |
| **Manual lesson (not curriculum-linked)** | Lesson (Manual) — Not linked to a curriculum unit. | Optional: Attach to Unit |

## 6️⃣ Backlog Language

Backlog is not failure. Backlog is “unscheduled lessons.”

| Element | Copy |
|--------|------|
| **Header** | Lesson Backlog |
| **Description** | Lessons not yet scheduled. |
| **Action** | Schedule into Slots |

---

## 7️⃣ System-Wide Microcopy Rules

**Never mix these terms:**

| Wrong | Correct |
|-------|--------|
| “Plan created 120 lessons” | “Plan created 120 instructional slots” |
| “Fill lesson” | “Fill slot” |
| “Create event” (for curriculum) | “Schedule lesson” |
| “Lesson created” (for parsing) | “Draft lesson created” |

---

## 8️⃣ Modal Relationship Summary (User Mental Model)

| When user thinks… | → Surface | → Result |
|--------------------|-----------|----------|
| I need to decide **when** school happens. | Plan My Year | generates slots |
| I need to decide **what** we’re teaching. | Build Curriculum | creates units + lessons |
| I have a syllabus. | Import & Extract | creates draft lessons, then attach to unit |
| I see an empty spot on my calendar. | Fill Slot | — |

---

## 9️⃣ Subtle but Powerful Language Alignment

**Change this everywhere:**

| Old | New |
|-----|-----|
| “Lesson generated by Plan My Year” | “Instructional slot generated by Plan My Year” |
| “Convert to custom event” | “Detach from curriculum” |

---

## 🔟 Visual Labeling Suggestions (Optional but Strongly Recommended)

Use subtle badges:

- 🟦 **Slot** — instructional slot (empty)
- 🟢 **Scheduled Lesson** — filled / curriculum-linked
- 🟡 **Backlog** — unscheduled lesson
- ⚪ **Manual Event** — one-off, not curriculum-linked

Even small 10px pills in the corner dramatically reduce cognitive confusion.

---

## Final Principle

**If language is correct:**

- Plan My Year feels like **infrastructure**.
- Curriculum feels like **structure**.
- Slots feel like **containers**.
- Lessons feel like **content**.

**If language is sloppy:**  
Everything collapses back into “random lessons on a calendar.”
