# Assets Directory

## Logo Image
Please save your Learnadoodle logo image as `learnadoodle-logo.png` in this directory.

The logo should be:
- PNG format
- High resolution: at least **840px wide** recommended so the ID card export is not grainy (header use is smaller)
- Transparent background preferred
- The glowing blue logo with paw print icons as described

The image will be automatically resized to fit the header (150px wide, 32px tall). On the Family ID cards it displays at 420px wide; export uses 4x resolution, so a 840px+ wide source keeps the logo sharp.
